Future State Journey: Delivery Driver

Strategy: reclaim operational simplicity by stripping legacy noise and making the tool the fastest for everyday work.

Persona: Delivery driver (the disengaging frontline user)  |  Goal: Mark each stop delivered quickly and move on without fighting the app.
Today Tap→Tap→Tap →gives up→ texts dispatcher→board goes stale
1

Start the Route

User Action
Taps Start Route on a clean home screen → shift begins in one tap.
Internal State
Confident the app is ready → no hunting through menus.
Pain Point Addressed
Core actions buried 2-3 levels deep → surfaced as the primary action. BUG-2079, UXR-11
2

Arrive and Deliver

User Action
Views a single-stop screen on arrival → attention stays on the delivery.
Internal State
Focused and unhurried → the app stays out of the way.
Pain Point Addressed
Feature clutter and nested menus → only essential stop tasks remain. UXR-04, UXR-08
3

One-Tap Complete

User Action
Taps one large Mark Delivered button → done at the doorstep, one-handed.
Internal State
Relieved and in control → no reason to reach for a text message.
Pain Point Addressed
Three taps across three screens → single-tap completion. BUG-2055, UXR-01
4

Sync and Surface

User Action
Walks to the next stop → photo and status sync in the background.
Internal State
Trusts the delivery is recorded → stops double-reporting to dispatch.
Pain Point Addressed
Off-platform texting and stale dashboards → admins see accurate status. UXR-09, BUG-2072, BUG-2061

3 Competitive Advantages Over the Manual Workaround

1. Faster at the doorstepOne tap in the app beats opening a second app and typing one-handed.
2. Self-updating recordsEach completion is timestamped and written to the dispatcher board, so no one reconciles texts by hand.
3. Built-in proof of deliveryPhotos attach to the stop and retry on weak signal, which a text cannot do.

Notes: Internal State reflects the driver's mindset at each stage, not system behavior. Cached stop lists, photo auto-retry, and background sync are proposed solutions; the research documents only the problems, so validate with engineering. The single-stop view in Stage 2 is inferred from the "legacy noise" strategy, not requested directly by drivers.
